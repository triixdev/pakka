# Pakka

A private evidence binder for renters with no written agreement. Log what the landlord said aloud. Send it back as a written confirmation. Fingerprint room photos. Build a move out pack to ask for your deposit back.

## Run
Double click index.html. No install and no server. Entries stay in your browser on your device.

## Privacy
No account and no backend. No analytics. A strict Content Security Policy blocks all requests. Optional passphrase encryption uses AES-GCM. The only outside handoff is the WhatsApp link, which opens only when you tap it.

## Planning docs
The Devpost Learn Skill Pack planning files are in the devpost folder: scope.md, prd.md, spec.md and checklist.md.

## Built with
Plain HTML, CSS and JavaScript. Web Crypto and IndexedDB. Drafted and built with AI coding assistants (Claude and Codex) during the submission period. No pre-existing code was used.
